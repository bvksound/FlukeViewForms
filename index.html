Fluke 287 Live Viewer

Read a Fluke 287 through its IR cable, watch the display live, and record readings to CSV. Everything runs in your browser — nothing is uploaded.

Not connected

This browser has no Web Serial support. Use Chrome, Edge or Opera on macOS, Windows or Linux (Firefox and Safari can't talk to serial ports). The page must be served over https://.

Reads what is stored on the meter: saved measurements, min/max and peak sessions, and recordings. Saved measurements and downloaded recordings are plotted in the graph above. Read-only: nothing on the meter is changed or erased.

Connect a meter to use the reset and raw command tools.

Reset

Default setup

Resets the Hz trigger edge, pulse width and duty cycle polarity, and the continuity beeper. Does not touch other settings.

Reset meter properties

Same as Reset Setup on the meter's front-panel Setup menu.

Reset instrument

Restores all meter settings to factory defaults (calibration is kept). Same as Reset Meter in Setup.

Raw command

Send any command to the meter and see every reply line. Commands end with a carriage return automatically. Commands the public Fluke spec doesn't document may change meter settings, so use with care.
