Meter Memory

Meter Memory

Reads what is stored on the meter: saved measurements, min/max and peak sessions, and recordings. Use View in graph to plot saved measurements, a recording or a min/max or peak session in the Graph section, where it can be exported. Read-only: nothing on the meter is changed or erased.

Report

Build a PDF report on the page below. Fill in the fields, add a logo if you like, then add what belongs in it: a copy of the graph (live or from the meter's memory, only the cursor window if you set cursors) and/or the Saved readings table, each with a description. The fields and logo are remembered for next time.

Connect a meter to use the reset and raw command tools.

Reset

Default setup

Resets the Hz trigger edge, pulse width and duty cycle polarity, and the continuity beeper. Does not touch other settings.

Reset meter properties

Same as Reset Setup on the meter's front-panel Setup menu.

Reset instrument

Restores all meter settings to factory defaults (calibration is kept). Same as Reset Meter in Setup.

Raw command

Send any command to the meter and see every reply line. Commands end with a carriage return automatically. Commands the public Fluke spec doesn't document may change meter settings, so use with care.
